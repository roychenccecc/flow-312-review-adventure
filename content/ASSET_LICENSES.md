## 字体、图标与声音

- 字体：只使用 CSS 系统字体栈，不下载或再分发字体文件。
- 界面图标：`lucide-react`，Lucide 项目采用 ISC License；图标以依赖方式打包。
- 音乐与音效：`src/lib/audio.ts` 通过 Web Audio API 在设备上程序化合成，无外部录音、乐曲或角色配音文件。
- UI 组件：基于项目依赖中的 React、Base UI、shadcn 与相关开源包；具体版本锁定在 `package-lock.json`。

## 合规发布检查

发布前需确认：

1. `dist/` 中只含本表列出的原创图像、程序代码和已登记的开源依赖。
2. 新增人物视觉必须先核对理论象征，再补充本表。
3. 不得把照片、教材插图、游戏截图或第三方音乐直接放入 `public/`。
4. 若重新生成素材，应保留新配方、日期和用途，并同步提升 service worker 缓存版本。
